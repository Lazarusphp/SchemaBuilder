# LazarusPhp SchemaBuilder

## What is SchemaBuilder
Lazarus php SchemaBuilder is a sub component to the lazarus framework and is designed to create mysql Database Schema with ease.

## Supported Features
The SchemaBuilder has the abilility to create new columns along with the ability to set attributes, default values primary and foreign keys as well as indexes and unique keys.

As well as Creating schemas, it also has the ability to modify and delete colums values and keys.

## Installation

```php
composer require lazarusphp/schemabuilder
```
